extra/fpga/zc706-sdboot/fsbl.elf is a compiled binary. It is built from the Zynq-7000 first stage boot
loader and the standalone BSP that ship with AMD Vivado, in
data/embeddedsw/lib/sw_apps/zynq_fsbl, plus the ps7_init for this board taken from the ZC706
hardware platform in data/embeddedsw/lib/fixed_hwplatforms/zc706.xsa.

Those sources carry the MIT licence and the first notice below. Note that the board initialisation
code used here is ps7_init.c, the MIT licensed variant, and NOT ps7_init_gpl.c.

The loader reads the bitstream out of BOOT.BIN on the SD card through the xilffs library, which
build_fsbl.tcl adds to the BSP. xilffs wraps ChaN's FatFs, and FatFs carries its own terms, the
second notice below. Vivado 2026.1 supplies FatFs R0.16. Earlier releases carry the same terms with
an earlier year.

Rebuild the binary from the same sources with build_fsbl.tcl in the same directory.
